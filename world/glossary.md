# 术语表

> 这个世界里的人不说"永生技术"。他们有自己的语言。

---

## 技术与医学

| 术语 | 含义 |
|------|------|
| **干预** | 延寿治疗的通称。"你做过干预了吗？"是这个时代最敏感的问题之一。 |
| **窗口期** | 延寿干预有效的年龄/身体状态范围。错过窗口期 = 被永生列车抛下。 |
| **深度干预** | 全面的逆转治疗（每10-15年一次）。昂贵、耗时、有风险。 |
| **维护** | 日常的抗衰老保养。相对便宜。不能逆转，只能延缓。 |
| **2038事件** | 首次成功的人体逆转实验。改变人类历史的转折点。 |
| **生理年龄 / 日历年龄** | 身体状态 vs 实际存活年数。"他日历150，生理35。" |
| **免疫债务** | 反复重编程导致的免疫偏差。长寿者的隐性代价。 |

## 社会与身份

| 术语 | 含义 |
|------|------|
| **延寿者** | 至少接受过一次干预的人。 |
| **暂寿者** | 未接受过干预的人。官方用词。民间有更难听的说法。 |
| **窗口遗弃者** | 技术出现时已超过窗口期的人。正在消失的群体。 |
| **自然选择者** | 有条件但拒绝延寿的人。极少数。 |
| **初代** | 最早一批（2045-2060年间）接受干预的人。权力最大的群体。 |
| **原生者** | 从出生就被纳入延寿体系的人。不理解"怕死"是什么感觉。 |
| **再生** | 长寿者主动"重启"人生——换地点、换身份、断旧关系。不是技术概念，是生活选择。 |
| **大关闭** | ~2050年，首批大规模窗口期关闭事件。约12亿人被永久排除。 |
| **世界变灰** | 超长寿者的心理综合征。情绪钝化、兴趣消退、存在性空虚。 |
| **告别仪式** | 为即将自然衰老死去的人举行的文化仪式。带有尊严和悲伤。 |

## 关系与家庭

| 术语 | 含义 |
|------|------|
| **周期契约** | 有明确期限的婚姻合同。到期可续签、修改或终止。最常见的婚姻形态。 |
| **生命线伴侣** | 没有期限的伴侣关系。极少数人的选择。被视为浪漫主义的极致或"情感极限运动"。 |
| **社会化抚养** | 公共/社区承担主要育儿责任的制度。有多种模式，争议持续。 |

## 经济与权力

| 术语 | 含义 |
|------|------|
| **时间信用** | 基于"预期剩余寿命"的信用评级。延寿者评级天然高于暂寿者。 |
| **生命时间证券** | 将个人未来的生命时间打包为金融产品。可以卖出自己"未来的时间"。 |
| **LifeArc** | 最大的延寿技术联合体。控制约40%全球市场。 |
| **ChronoBank** | 最大的时间金融公司。"卖时间"就是和它做生意。 |
| **SoilNet** | 南方联合数据合作社。32国联盟。对抗数据殖民。 |
| **数据殖民** | 北方从南方大规模采集生物数据，用于研发延寿技术，南方人用不起成果。 |

## 文化与思潮

| 术语 | 含义 |
|------|------|
| **延续主义** | 主流意识形态：延长生命即正义，技术进步不可阻挡。 |
| **自然主义** | 反对延寿：死亡是人的本质，拒绝是守护人性。 |
| **平等主义** | 延寿权即人权，必须全民普及。南方运动的核心立场。 |
| **虚无派** | 活多久都没意义。长寿者中增长最快的文化。 |
| **裂缝** | 系统边缘的非正式社区和生活方式。不被量化、不被优化的空间。 |

## 空间

| 术语 | 含义 |
|------|------|
| **裂缝社区** | 大城市边缘的非正式社区。量化系统的盲区。 |
| **延寿飞地** | 超级富豪的私人领地。不属于任何国家。 |
| **技术主权国** | 拥有独立延寿技术能力的国家。全球约15个。 |
| **技术边缘国** | 无力获取延寿技术的国家。国民基本是暂寿者。 |
